# Clothing Image Style

Use this prompt when generating replacement clothing images for the dressing app.

## Base Prompt

Bright flat toddler-friendly clothing illustration of a single real clothing item, centered composition, clean recognizable silhouette, soft rounded edges, cheerful but realistic colors, consistent warm studio lighting, polished app-icon illustration style, subtle soft shadow, transparent background or pure white background, no text, no labels, no person, no mannequin, no hanger, no extra objects.

## Consistency Notes

- Generate one item per image.
- Keep the item large and easy for a 3-year-old to recognize.
- Use the same camera angle across all items: front-facing or slightly top-front.
- Use simple readable shapes, but do not make the item look like an emoji, sticker, toy, or exaggerated cartoon.
- Avoid fashion styling, adult clothing presentation, brand marks, logos, and decorative text.
- Use a 1:1 square canvas, ideally 400x400 px or larger.

## Negative Prompt

photorealistic, model, child wearing clothes, adult fashion, hanger, store display, logo, text, watermark, busy background, multiple clothing items, dark colors, harsh shadows, realistic fabric wrinkles, clutter, emoji, sticker, toy-like, exaggerated cartoon, thick black outline, kawaii face

## Dinosaur Reward Prompt

Friendly dinosaur character for a toddler reward screen, gentle happy expression, approachable proportions, polished flat illustration style, cheerful colors, soft studio lighting, subtle shadow, centered composition, transparent background or pure white background, no text, no scary teeth, no realistic scales, no clutter.

Generate several species in the same style: stegosaurus, tyrannosaurus, triceratops, and brontosaurus. Keep them cute, chunky, and safe-looking for toddlers.

Avoid emoji-like dinosaurs, toy plastic texture, aggressive poses, sharp teeth, monster style, excessive cartoon exaggeration, and thick black outlines.
